# 后期：部署与运维

iPad 长期插电、常亮挂墙使用时需要的配置。

## 1. 安装

1. 准备 HA 长期访问令牌：HA 网页 → 个人资料 → 安全 → 长期访问令牌，保存到 Mac 的 `~/.config/homeview/ha_token`（`chmod 600`）
2. `cd app && cp config.example.json config.json`，把里面的地址和实体改成自己的
3. 执行 `sh build.sh`，生成 `dist/HomeView.tipa`
4. 把 `.tipa` 放到 iPad 的“文件 → 我的 iPad”（可以 AirDrop，也可以用 `tools/deploy.sh tipa`，后者需要先设置 `FILES`，见脚本开头的注释），在 iPad 上用 TrollStore 安装
5. 执行 `IPAD=mobile@<iPad IP> tools/deploy.sh config`，把配置和令牌写进应用沙盒，文件权限为 600
6. 打开 HomeView。之后只改网页的话用 `deploy.sh web` 推送，不用重装

建议同时在 iPad 上设置：
- 设置 → 显示与亮度 → 自动锁定：**永不**
- 关闭“原彩显示”和“自动亮度”，亮度交给应用的夜间调暗来管
- 设置 → 辅助功能 → 引导式访问（可选），防止误退出

## 2. 防烧屏

iPad Air 2 是 LCD，不会像 OLED 那样烧屏，但长期显示静态画面会有**残影**：

- 像素偏移：整个界面每 90 秒挪一步，沿 4×4 px 的方形路径循环（`pixel_shift: false` 可关闭）
- 动态壁纸一直在缓慢变化；空闲时只以 20 fps 刷新壁纸

## 3. 夜间自动调暗（只调亮度，不降帧）

```json
"night": { "start": "00:00", "end": "07:00", "brightness": 0.15, "day_brightness": 0.6 }
```

到了时间段，亮度会平滑过渡到 15%，结束后回到 60%。调亮度通过原生指令 `UIScreen.main.brightness` 实现；调暗状态存在 `localStorage` 里，页面重新加载也不会丢。

## 4. 电池保护（长期插电防鼓包）

用的是 [ChargeLimiter](https://github.com/lich4/ChargeLimiter)（越狱插件，带一个守护进程）。当前配置：

| 项目 | 值 | 原因 |
| --- | --- | --- |
| 充电上限 / 恢复充电 | **60% / 50%** | 锂电池在中等电量下长期存放，老化最慢 |
| 温度保护 | 开启 | 温度过高时停止充电 |
| 智能停充 | 开启 | 到上限后切断输入电流，iPad 直接用外部供电，不再小电流涓流充放 |

实测情况（循环次数 218 的旧电池）：
- 先放电到 60%，开启智能停充后，此前约 −18 mA 的持续放电降到 **0 mA**
- 电量降到 50% 时会自动回充，期间观察到 3 次，都正常
- 电池温度 23.6–32.5 °C

守护进程在 iPad 上提供本地接口，可以通过 SSH 查询：

```sh
ssh $IPAD "curl -s -X POST 127.0.0.1:1230/bridge -d '{\"api\":\"get_bat_info\"}'"
# 其他 api：get_conf、set_conf（key、val）、set_inflow_status（flag）
```

历史记录在 `/var/root/aldente.db`（表 day/hour/min5/month）。

## 5. Home Assistant 端

### 只控制插座 USB 口的“灯”

有些智能插座带一个可以单独开关的 USB 口，比如氛围灯插在 USB 上。如果直接用整个插座的电源开关，会把插座上的其他东西也一起断掉。做法：

1. 设置 → 设备与服务 → 辅助元素 → 新建 → **更改开关的设备类型**（`switch_as_x`）
2. 开关选**插座的 USB 开关**（不要选整个插座的电源开关），类型选“灯”
3. 给新生成的 `light.*` 取个名字（比如“氛围灯”），分配到对应区域；然后在 `config.json` 的 `home` 里引用它

### HomeKit 桥：只暴露需要的实体

HomeKit Bridge 用 `include_entities` 白名单，只同步要用的几盏灯。

> ⚠️ **踩过的坑**：在 HomeKit Bridge 的“选项”里，**只勾选下面确实选了实体的类型**。如果勾了“开关”类型却一个开关实体都没选，HA 会把它当成 `include_domains`，把**所有开关**都同步给 HomeKit，家庭 App 里一下子多出一大堆开关。

> 换了实体以后（比如上面改成 USB 开关），HomeKit 会把它当成**新配件**，放进默认房间。HomeKit 不会读取 HA 的区域，需要在家庭 App 里长按配件 → 设置 → 房间，手动移过去。

改配置之前建议先备份 `/config/.storage/core.config_entries` 和 `core.entity_registry`。
