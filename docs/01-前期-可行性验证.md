# 前期：可行性验证

正式开发前，要先回答一个问题：一台 2014 年的 iPad Air 2（A8X、2 GB 内存，最高只能升到 iPadOS 15.8），能不能**独立**跑一个 HomeView 风格的中控屏？

## 约束

1. 运行时不依赖 Mac（Mac 只用来编译）
2. 直接在局域网里连接家中 OpenWrt 上的 Home Assistant
3. 所有功能都在 iPad 本机执行；之后的 AI 部分用云端 VPS 或本地 Agent 做理解，动作仍由 iPad 本地执行

## 设备准备

- iPadOS 15.8.8，Dopamine（rootless）越狱，装好 TrollStore 和 OpenSSH
- Mac 通过 `ssh mobile@<iPad>` 免密登录（只用于部署和读日志；不需要 root）
- 安装包用 TrollStore 安装：Mac 把 `.tipa` 拷到“文件 → 我的 iPad”，在 iPad 上点安装

## 方案选择

| 方案 | 结论 |
| --- | --- |
| 原生 UIKit/SwiftUI 实现玻璃效果 | iOS 15 没有 Liquid Glass；自己用 Metal 写，工作量大 |
| Safari 网页或添加到主屏幕 | 拿不到亮度、文件、麦克风回声消除等原生能力，后台也会被冻结 |
| **WKWebView 外壳 + WebGL** | ✅ 采用：界面用 Web 写，迭代快（推送网页就能热更新）；原生层只负责亮度、文件、日志和麦克风 |

## 测试 1：GPU 帧率（`spike/index.html`）

全屏 WebGL 动态壁纸，加上玻璃磁贴（背景模糊、折射、高光），在不同渲染倍率下各跑 300 帧：

| 渲染倍率 | 分辨率 | fps | p95 帧间隔 |
| --- | --- | --- | --- |
| 1x | 1024×768 | 60 | 18 ms |
| **1.25x** | 1280×960 | **59.4** | 19 ms |
| 1.5x | 1536×1152 | 50 | 21 ms |
| 2x（原生） | 2048×1536 | 36 | 29 ms |

**结论**：玻璃层按 1.25x 渲染，文字和图标交给 DOM，保持原生分辨率。这样画面清晰，帧率也够。原始数据见 `spike/results/ipad.jsonl`。

## 测试 2：麦克风

开启系统的语音处理（回声消除）后用 16 kHz 采集：
- 采集本身只占 CPU 约 3%
- 环境底噪 p50 约 −41 dB

## 测试 3：Home Assistant 延迟（`spike/app/web/ha.html`）

| 指标 | 结果 |
| --- | --- |
| WebSocket 连接 + 鉴权 | 84 + 98 ms |
| 拉取全部状态（359 个实体） | 34 ms |
| ping 中位数 | 12 ms |
| 点开关到收到新状态的中位数 | **145 ms** |
| 摄像头快照 | 3.2 s（太慢，后来干脆去掉了摄像头功能） |

原始数据见 `spike/results/ipad-ha.jsonl`。

## 测试 4：本地唤醒词（`spike/app/Kws.swift`）

- 引擎：sherpa-onnx v2.0.1，静态编译成 iOS arm64 版本（`spike/vendor/build-sherpa-ios.sh`）
- 模型：`sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20`（int8 量化）
- 候选唤醒词见 `spike/models/keywords_hv.txt`

| 指标 | 结果 |
| --- | --- |
| 模型加载 | 2.3 s |
| 实时率 RTF | 0.17 |
| CPU 占用 | 约 22%（单核） |
| “你好小家”，旁边同时在放视频 | 10 次唤醒成功 7–8 次 |
| “HomeView” | 明显更差 |

**结论**：主唤醒词定为“你好小家”。原始数据见 `spike/results/ipad-kws-positive.jsonl`。

### 复现

```sh
cd spike
git clone --depth 1 -b v2.0.1 https://github.com/k2-fsa/sherpa-onnx vendor/sherpa-onnx
# 按 sherpa-onnx 的 build-ios.sh 下载 onnxruntime.xcframework 到 vendor/sherpa-onnx/build-ios-hv/ios-onnxruntime/
sh vendor/build-sherpa-ios.sh            # 需要 cmake 和 ninja（脚本默认在 ../.tools/bin 找）
curl -LO https://github.com/k2-fsa/sherpa-onnx/releases/download/kws-models/sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20.tar.bz2
tar xf sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20.tar.bz2 -C models
python3 serve.py                         # Mac 上接收测试结果；先把 app/main.swift 里的 collector 改成这台 Mac 的地址
sh app/build.sh                          # 生成 dist/HVSpike.tipa
```

## 最终决定

- 可行：WKWebView + WebGL（1.25x）+ HA WebSocket 直连，全部在 iPad 上跑
- 摄像头不放进中控屏
- 语音唤醒技术上可行，先放一放，等后续的 AI 助手阶段再接入
