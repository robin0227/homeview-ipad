## 渲染管线（glass.js）

1. 动态壁纸按半分辨率绘制，然后放大成全尺寸背景
2. 背景缩到 1/4 尺寸**只模糊一次**，所有玻璃磁贴共用这张模糊图
3. 每个磁贴在 shader 里做折射、边缘高光和染色；玻璃文字（大数字等）先画成纹理遮罩（R 通道存模糊后的高度，A 通道存覆盖度），再走同一套玻璃 shader
4. 整个 WebGL 层按 `render_scale`（默认 1.25）渲染；文字和图标在 DOM 层，保持原生分辨率
5. 交互时（拖动、按压）冻结壁纸，直接复用上一帧的背景，只重画玻璃，保证跟手
6. 全程只有一个 `requestAnimationFrame` 循环；`pointermove` 时直接触发重绘；弹簧动画按各自单位设定收敛阈值

实测：滑动 p95 18 ms，按压时没有超过 20 ms 的帧。

## 页面

翻页顺序：**表盘 ← 主页 → 设备 → 应用**

- **表盘**：小组件、数字、单行、指针、大数字、信息、天气、日历，共 8 种；长按打开表盘库
- **背景**：液态、极光、气泡、纯色、照片、弥散、丝绸、光环、星空
- **数字样式**：玻璃、高亮、气泡、实色
- **照片背景**：可以多选，单图显示，或者每 30 秒、1 分钟、5 分钟渐变切换
- **主页**：4×3 网格（竖屏时 3×4），磁贴类型有 `clock`、`weather`、`climate`、`light`
- **设备**：列出全部灯和媒体播放器，离线设备排在最后，点一下就能开关
- **应用**：计时器（带边缘进度环和提示音）、天气（逐小时和每日预报）

## 配置（config.json）

参考 [`app/config.example.json`](../app/config.example.json)：

| 键 | 说明 |
| --- | --- |
| `ha_url` | HA 地址 |
| `token` | **不要写在这里**，由 `deploy.sh config` 从 `~/.config/homeview/ha_token` 自动加上 |
| `render_scale` | 玻璃层渲染倍率，默认 1.25 |
| `wallpaper` | `style`（0–8）、`tint`、`animated`、`speed` |
| `home` | 主页磁贴：`type`、`entity`、`name`、`room`、`at: [列, 行, 宽, 高]` |
| `night` | `start`、`end`、`brightness`（夜间亮度）、`day_brightness`（白天亮度）；设为 `false` 关闭 |
| `pixel_shift` | 设为 `false` 关闭像素偏移 |
| `latitude` / `longitude` | Open-Meteo 用的坐标，默认取 HA 的家庭位置 |
| `selftest` | 改成一个新的值，iPad 就会自动跑一轮滑动和按压测试，并把性能写进日志 |

## 开发流程

```sh
python3 tools/dev-server.py      # Mac 浏览器预览，连接真实的 HA
export IPAD=mobile@<iPad IP>
tools/deploy.sh web              # 推送网页，iPad 3 秒内自动刷新，不用重装
tools/deploy.sh config           # 推送配置和令牌
tools/deploy.sh log 50           # 查看 iPad 日志（JSON Lines）
sh build.sh                      # 只有改了 native/ 才需要重新打包，再用 TrollStore 安装
```

`build.sh` 默认使用 `/Applications/Xcode-beta.app`，可以用环境变量 `DEVELOPER_DIR` 换成别的 Xcode。编译目标是 `arm64-apple-ios15.0`，ad-hoc 签名。

## 一路上遇到的问题

- `img.decode()` 在 iOS 15 上偶尔一直不返回 → 改用 `onload` 加超时
- 弹簧动画的收敛阈值共用一个值，导致按压和染色动画直接跳到终点 → 每种单位单独设阈值
- 在 Mac 上预览时开发服务器连接被重置 → 把 `request_queue_size` 调到 64
- 调亮度会触发页面重新加载，导致调暗状态丢失 → 状态存进 `localStorage`
- HA 不可用时天气显示 NaN → 加空状态，并自动切换到 Open-Meteo
